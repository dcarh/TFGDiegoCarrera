# Episodios de TV

## Detalles

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}/episode/{episode_number}

Consulta los detalles de un episodio de una serie de televisión.

Este método admite el uso de append_to_response. Lee más sobre esto aquí.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetros obligatorios.

- season_number (int32). Parámetros obligatorios.

- episode_number (int32). Parámetros obligatorios.

#### PARÁMETROS DE CONSULTA

- append_to_response (string). Lista separada por comas de puntos finales dentro de este espacio de nombres, máximo 20 elementos

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Cambios

GET https://api.themoviedb.org/3/tv/episode/{episode_id}/changes

Obtener los cambios recientes para un episodio de una serie de televisión.

Obtén los cambios para un episodio de una serie de televisión. Por defecto, solo se devuelven las últimas 24 horas.

Puedes consultar hasta 14 días en una sola consulta utilizando los parámetros de consulta start_date y end_date.

    📘 Nota

    Los cambios en los episodios de series de televisión son un poco diferentes que los cambios en películas en el sentido de que hay algunas ediciones en episodios que crearán una entrada de cambio de nivel superior en el nivel de la temporada. Estos se pueden encontrar bajo las claves de episodio. Estas claves contendrán un episode_id. Puedes usar los métodos de cambios de episodio para buscarlos individualmente.

#### PARÁMETROS DE RUTA

- episode_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Imágenes

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}/episode/{episode_number}/images

Obtener las imágenes que pertenecen a un episodio de una serie de televisión.

Este método devolverá los fondos que se han agregado a un episodio de una serie de televisión.

    📘 Nota

    Si tienes un idioma especificado, actuará como un filtro en los elementos devueltos. Puedes usar el parámetro include_image_language para consultar idiomas adicionales.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetros obligatorios.

- season_number (int32). Parámetros obligatorios.

- episode_number (int32). Parámetros obligatorios.

#### PARÁMETROS DE CONSULTA

- include_image_language (string). Especifica una lista separada por comas de valores ISO-639-1 para consultar, por ejemplo: en,null

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200
