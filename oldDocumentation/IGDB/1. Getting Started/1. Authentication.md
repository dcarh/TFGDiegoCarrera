# Autenticación

Ahora que tienes un ID de cliente (Client ID) y un secreto de cliente (Client Secret), autenticarás como un desarrollador de Twitch utilizando OAuth2. Puedes encontrar información detallada en la documentación de Twitch Developer [https://dev.twitch.tv/docs/authentication/].

Realiza una solicitud POST a https://id.twitch.tv/oauth2/token con los siguientes parámetros de cadena de consulta, sustituyendo tu ID de cliente y secreto de cliente según corresponda.

- client_id=ID de Cliente
- client_secret=Secreto de Cliente
- grant_type=client_credentials

#### Ejemplo:

Si tu ID de cliente es "abcdefg12345" y tu secreto de cliente es "hijklmn67890", la URL completa debería verse así:

    POST: https://id.twitch.tv/oauth2/token?client_id=abcdefg12345&client_secret=hijklmn67890&grant_type=client_credentials

La respuesta a esto será un objeto JSON que contiene el token de acceso y el número de segundos hasta que el token caduque.

    {
    "access_token": "access12345token",
    "expires_in": 5587808,
    "token_type": "bearer"
    }
    
Nota: El campo "expires_in" muestra el número de segundos antes de que el access_token caduque y deba renovarse.
