JSON y JSONP

El único formato de respuesta que TMDB admite es JSON.

Si estás utilizando una biblioteca de JavaScript y necesitas realizar solicitudes desde otro dominio público, puedes utilizar el parámetro de callback, que encapsulará la respuesta JSON en una función de JavaScript para ti.

Ejemplo de solicitud JSONP

    curl --request GET \
        --url 'https://api.themoviedb.org/3/search/movie?query=Batman&callback=test' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'
