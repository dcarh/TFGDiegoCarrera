# Películas

## Detalles

GET https://api.themoviedb.org/3/movie/{movie_id}

Obtener los detalles principales de una película por ID.

### Append To Response

Este método admite el uso de append_to_response. Lee más sobre esto aquí [https://developer.themoviedb.org/docs/append-to-response].

#### PARÁMETROS DE RUTA

- movie_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- append_to_response (string). Lista separada por comas de endpoints dentro de este espacio de nombres, máximo 20 elementos

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Cambios

GET https://api.themoviedb.org/3/movie/{movie_id}/changes

Obtener los cambios recientes para una película.

Obtén los cambios para una película. Por defecto, solo se devuelven las últimas 24 horas.

Puedes consultar hasta 14 días en una sola consulta utilizando los parámetros de consulta start_date y end_date.

#### PARÁMETROS DE RUTA

- movie_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- end_date (date)
- page (int32)
- start_date (date)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Imágenes

GET https://api.themoviedb.org/3/movie/{movie_id}/images

Obtener las imágenes que pertenecen a una película.

Este método devolverá los fondos, carteles y logotipos que se han agregado a una película.

    📘 Nota

    Si tienes un language especificado, actuará como un filtro en los elementos devueltos. Puedes usar el parámetro include_image_language para consultar otros idiomas adicionales.

#### PARÁMETROS DE RUTA

- movie_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- include_image_language (string). Especifica una lista separada por comas de valores ISO-639-1 para consultar, por ejemplo: en,null.

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Fechas de Estreno

GET https://api.themoviedb.org/3/movie/{movie_id}/release_dates

Obtener las fechas de estreno y certificaciones para una película.

Los tipos de estreno y estados utilizados en TMDB son los siguientes:

|Estreno|Tipo
|-|-
|Premiere|1
|Limitado en Cines|2
|En Cines|3
|Digital|4
|Físico|5
|TV|6

#### PARÁMETROS DE RUTA

- movie_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Proveedores de Transmisión

GET https://api.themoviedb.org/3/movie/{movie_id}/watch/providers

Obtener la lista de proveedores de transmisión que tenemos para una película.

Impulsado por nuestra asociación con JustWatch, puedes consultar este método para obtener una lista de las disponibilidades de transmisión/alquiler/compra por país según el proveedor.

Esto no devolverá enlaces profundos completos, sino que es solo suficiente información para mostrar lo que está disponible y dónde.

Puedes enlazar a la URL proporcionada por TMDB para ayudar a respaldar a TMDB y proporcionar los enlaces profundos reales al contenido.

    📘 Atribución de JustWatch Requerida

    Para usar estos datos, debes atribuir la fuente de los datos a JustWatch. Si encontramos algún uso que no cumpla con estos términos, revocaremos el acceso a la API.

#### PARÁMETROS DE RUTA

- movie_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200
