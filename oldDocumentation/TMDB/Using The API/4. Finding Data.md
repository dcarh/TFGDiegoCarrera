# Encontrar datos

Hay 3 formas de buscar y encontrar películas, programas de televisión y personas en TMDB. Se detallan a continuación.

## /search (Para más info, https://developer.themoviedb.org/reference/search-movie):

La búsqueda basada en texto es la forma más común. Proporcionas una cadena de consulta y TMDB proporciona la coincidencia más cercana. La búsqueda por texto tiene en cuenta todos los nombres y títulos originales, traducidos y alternativos.

Es de tipo application/json.

Se pueden buscar: 

- Películas (https://api.themoviedb.org/3/search/movie): 

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - include_adult (boolean)
        - language (string)
        - primary_release_year (string)
        - page (int32)
        - region (string)
        - year (string)

- Series de TV (https://api.themoviedb.org/3/search/tv):

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - first_air_date_year (string)
        - include_adult (boolean)
        - language (string)
        - page (int32)
        - year (string)

- Personas (https://api.themoviedb.org/3/search/person): 

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - include_adult (boolean)
        - language (string)
        - page (int32)

- Colecciones (https://api.themoviedb.org/3/search/collection):

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - include_adult (boolean)
        - language (string)
        - page (int32)
        - region (string)

- Palabras clave (https://api.themoviedb.org/3/search/keyword): 

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - page (int32)

- Compañías (https://api.themoviedb.org/3/search/company): 

    - Parámetros de consulta:

        - query (string) -> Parámetro obligatorio
        - page (int32)

- Varias de las anteriores en una sola consulta (https://api.themoviedb.org/3/search/multi): 

    - Parámetros de consulta:
    
        - query (string) -> Parámetro obligatorio
        - include_adult (boolean)
        - language (string)
        - page (int32)



## /discover (Para más info, https://developer.themoviedb.org/reference/discover-movie):

A veces es útil buscar películas y programas de televisión según filtros o valores definibles como calificaciones, certificaciones o fechas de lanzamiento. El método discover facilita esto.

Es de tipo application/json.

Filtrado Avanzado:

    Si especificas el parámetro de región, se utilizará la fecha de lanzamiento regional en lugar de la fecha de lanzamiento principal. La fecha devuelta será la primera fecha basada en tu consulta (es decir, si se especifica with_release_type). Es importante tener en cuenta el orden de los tipos de lanzamiento que se utilizan. Especificar 2|3 devolvería la fecha de lanzamiento limitado en cines en lugar de 3|2, que devolvería la fecha de lanzamiento en cines.

Lógica AND/OR:

    También ten en cuenta que varios filtros admiten separación por comas (,) o tuberías (|). Las comas se tratan como una consulta AND, mientras que las tuberías se tratan como una consulta OR. Esto permite un filtrado bastante complejo según tus resultados deseados.

Se pueden buscar: 

- Películas (https://api.themoviedb.org/3/discover/movie): 

    - Parámetros de consulta:

        - certification (string). use in conjunction with region
        - certification.gte (string). use in conjunction with region
        - certification.lte (string). use in conjunction with region
        - certification_country (string). use in conjunction with the certification, certification.gte and certification.lte filters
        - include_adult (boolean)
        - include_video (boolean)
        - language (string)
        - page (int32)
        - primary_release_year (int32)
        - primary_release_date.gte (date)
        - primary_release_date.lte (date)
        - region (string)
        - release_date.gte (date)
        - release_date.lte (date)
        - sort_by (string). Default: popularity.desc
        - vote_average.gte (float)
        - vote_average.lte (float)
        - vote_count.gte (float)
        - vote_count.lte (float)
        - watch_region (string)
        - with_cast (string). Can be a comma (AND) or pipe (OR) separated query
        - with_companies (string). Can be a comma (AND) or pipe (OR) separated query
        - with_crew (string). Can be a comma (AND) or pipe (OR) separated query
        - with_genres (string). Can be a comma (AND) or pipe (OR) separated query
        - with_keywords (string). Can be a comma (AND) or pipe (OR) separated query
        - with_origin_country (string)
        - with_original_language (string)
        - with_people (string). Can be a comma (AND) or pipe (OR) separated query
        - with_release_type (int32). Possible values are: [1, 2, 3, 4, 5, 6] can be a comma (AND) or pipe (OR) separated query, can be used in conjunction with region
        - with_runtime.gte (int32)
        - with_runtime.lte (int32)
        - with_watch_monetization_types (string). Possible values are: [flatrate, free, ads, rent, buy] use in conjunction with watch_region, can be a comma (AND) or pipe (OR) separated query
        - with_watch_providers (string). use in conjunction with watch_region, can be a comma (AND) or pipe (OR) separated query
        - without_companies (string)
        - without_genres (string)
        - without_keywords (string)
        - without_watch_providers (string)
        - year (int32)

- Series de TV (https://api.themoviedb.org/3/discover/tv): 

    - Parámetros de consulta:

        - air_date.gte (date)
        - air_date.lte (date)
        - first_air_date_year (int32)
        - first_air_date.gte (date)
        - first_air_date.lte (date)
        - include_adult (boolean)
        - include_null_first_air_dates (boolean)
        - language (string)
        - page (int32)
        - screened_theatrically (boolean)
        - sort_by (string). Default: popularity.desc
        - timezone (string)
        - vote_average.gte (float)
        - vote_average.lte (float)
        - vote_count.gte (float)
        - vote_count.lte (float)
        - watch_region (string)
        - with_companies (string). Can be a comma (AND) or pipe (OR) separated query
        - with_genres (string). Can be a comma (AND) or pipe (OR) separated query
        - with_keywords (string). Can be a comma (AND) or pipe (OR) separated query
        - with_networks (int32)
        - with_origin_country (string)
        - with_original_language (string)
        - with_runtime.gte (int32)
        - with_runtime.lte (int32)
        - with_status (string). Possible values are: [0, 1, 2, 3, 4, 5], can be a comma (AND) or pipe (OR) separated query
        - with_watch_monetization_types (string). Possible values are: [flatrate, free, ads, rent, buy] use in conjunction with watch_region, can be a comma (AND) or pipe (OR) separated query
        - with_watch_providers (string). Use in conjunction with watch_region, can be a comma (AND) or pipe (OR) separated query
        - without_companies (string)
        - without_genres (string)
        - without_keywords (string)
        - without_watch_providers (string)
        - with_type (string). Possible values are: [0, 1, 2, 3, 4, 5, 6], can be a comma (AND) or pipe (OR) separated query

### /find (Para más info, https://developer.themoviedb.org/reference/find-by-id):

La última, pero aún muy útil, forma de encontrar datos es mediante identificadores externos existentes. Por ejemplo, si conoces el ID de IMDB de una película, programa de televisión o persona, puedes ingresar ese valor en este método y te devolveremos cualquier cosa que coincida. Esto puede ser muy útil cuando ya tienes una herramienta existente y estás agregando nuestro servicio a la mezcla.

https://api.themoviedb.org/3/find/{external_id}

application/json

El método "find" facilita la búsqueda de objetos en nuestra base de datos mediante un identificador externo.
Este método buscará todos los objetos (películas, programas de televisión y personas) y devolverá los resultados en una única respuesta.

- Parámetros de ruta:

    - external_id (string) -> Parámetro obligatorio

- Parámetros de consulta: 

    - external_source (string) -> Parámetro obligatorio
    - language (string)


Echa un vistazo a la página de "detalles de búsqueda y consulta" (https://developer.themoviedb.org/docs/search-and-query-for-details) para obtener algunos flujos de trabajo básicos que puedes usar para buscar y consultar datos.
