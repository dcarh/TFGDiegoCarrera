# Lista de cambios.

### En Películas

GET https://api.themoviedb.org/3/movie/changes

### En  TV

GET https://api.themoviedb.org/3/tv/changes

### En Personas

GET https://api.themoviedb.org/3/person/changes

----

Puedes consultar este método hasta 14 días a la vez utilizando los parámetros de consulta **start_date** y **end_date**. Se devuelven 100 elementos por página.

#### PARÁMETROS DE CONSULTA

|Parámetro|Tipo de dato
|-|-|
|end_date|date
|page|int32 (valor predeterminado: 1)
|start_date|date

#### RESPUESTA

Código de estado: 200
