# Personas

## Detalles

GET https://api.themoviedb.org/3/person/{person_id}

Consulta los detalles principales de una persona.

### Anexar a la Respuesta

Este método admite el uso de append_to_response. Lee más sobre esto aquí [https://developer.themoviedb.org/docs/append-to-response].

### Géneros

|Valor|Género
|-|-
|0|No establecido / no especificado
|1|Femenino
|2|Masculino
|3|No binario

#### PARÁMETROS DE RUTA

- person_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- append_to_response (string). Lista separada por comas de endpoints dentro de este espacio de nombres, máximo 20 elementos

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Cambios

GET https://api.themoviedb.org/3/person/{person_id}/changes

Obtener los cambios recientes para una persona.

Obtén los cambios para una persona. Por defecto, solo se devuelven las últimas 24 horas.

Puedes consultar hasta 14 días en una sola consulta utilizando los parámetros de consulta start_date y end_date.

#### PARÁMETROS DE RUTA

- person_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- end_date (date)
- page (int32)
- start_date (date)

#### POSIBLES RESPUESTAS

    Código de estatus: 200
