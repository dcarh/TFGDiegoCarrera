# Canales De Televisión

## Detalles

GET https://api.themoviedb.org/3/network/{network_id}

#### PARÁMETROS DE RUTA

- network_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200


## Nombres Alternativos
GET https://api.themoviedb.org/3/network/{network_id}/alternative_names

Obtener los nombres alternativos de los canales de televisión.

#### PARÁMETROS DE RUTA

- network_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200


## Imágenes

GET https://api.themoviedb.org/3/network/{network_id}/images

Obtener los logotipos de las cadenas de televisión por identificación.

    📘 Nota

    Hay dos formatos de imagen compatibles para las empresas: PNG y SVG. Puedes ver qué tipo es el archivo original al mirar el campo file_type. Preferimos SVG ya que son independientes de la resolución y, como tal, el ancho y el alto solo están ahí para reflejar el activo original que se cargó. Un SVG se puede escalar adecuadamente más allá de esas dimensiones si lo llamas como PNG.

Para obtener más información sobre cómo se pueden usar SVG y PNG, lee este documento [https://developer.themoviedb.org/docs/images].

#### PARÁMETROS DE RUTA

- network_id (int32). Parámetro obligatorio.

#### POSIBLES RESPUESTAS

    Código de estatus: 200
