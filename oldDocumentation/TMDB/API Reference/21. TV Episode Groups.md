# Detalles

GET https://api.themoviedb.org/3/tv/episode_group/{tv_episode_group_id}

Obtener los detalles de un grupo de episodios de TV.

Los grupos admiten 7 tipos diferentes que se enumeran de la siguiente manera:

|Tipo|Nombre
|-|-
|1|Fecha de emisión original
|2|Absoluto
|3|DVD
|4|Digital
|5|Arco de la historia
|6|Producción
|7|TV

#### PARÁMETROS DE RUTA

- tv_episode_group_id (string). Parámetro obligatorio

#### POSIBLE RESPUESTA

    Código de estatus: 200
