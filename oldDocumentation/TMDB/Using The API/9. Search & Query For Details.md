# Buscar y Consultar Detalles

Un flujo de trabajo común aquí en TMDB es buscar una película (o programa de televisión, o persona) y luego consultar los detalles. Aquí hay una breve descripción de cómo se ve ese flujo.

## Búsqueda
Primero, vas a realizar una consulta a uno de los métodos de búsqueda de películas, programas de televisión o personas. Utilizaremos "Jack Reacher" y el método de películas para este ejemplo:

     Ejemplo de solicitud de búsqueda

     curl --request GET \
          --url 'https://api.themoviedb.org/3/search/movie?query=Jack+Reacher&api_key=API_KEY'

Esto devolverá algunos campos, y el que quieres observar es el campo "results". Este es un array y contendrá nuestros objetos estándar de la lista de películas. Aquí tienes un ejemplo del primer ítem:

## Consulta de Detalles
Con el ítem anterior en mano, puedes ver que el id de la película es 343611. Puedes usar ese id para consultar el método de detalles de la película:

     Ejemplo de consulta de detalles

     curl --request GET \
          --url 'https://api.themoviedb.org/3/movie/343611?api_key=API_KEY'

Esto devolverá todos los detalles principales de la película según se describe en la documentación de detalles de la película. También te sugeriría leer la documentación de "append to response" ya que explica cómo puedes realizar múltiples subpeticiones en una sola. Por ejemplo, con videos:
