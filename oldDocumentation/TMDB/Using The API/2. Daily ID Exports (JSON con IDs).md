# Daily ID Exports

En https://files.tmdb.org/p/exports/movie_ids_01_10_2023.json.gz se descarga un archivo en el que cada película es un objeto JSON del siguiente tipo:

    {"adult":false,"id":419,"original_title":"Vom Suchen und Finden der Liebe","popularity":2.46,"video":false}

No sé cómo será finalmente para acceder a cada película, pero, en caso de que hay que poner siempre el ID para realizar una petición, este archivo podría constituir una opción interesante de obtener dicho ID a través del nombre.

Estos archivos son creados cada día y están disponibles desde las 8:00 AM UTC, teniendo un periodo de caducidad de 3 meses. Por tanto, una opción sería comprobar la hora al intentar una petición y, si esta es la primera que se hace desde las 8:00 AM UTC, hacer la petición para descargar el archivo. 

Con el archivo ya descargado, supongo que lo único que habría que hacer es buscar un ID según el nombre de la película para poder realizar la petición.

Existen los siguientes exports:
|Elemento|URL ejemplo|
|-|-|
|Películas|https://files.tmdb.org/p/exports/movie_ids_MM_DD_YYYY.json.gz|
|Series|https://files.tmdb.org/p/exports/tv_series_ids_MM_DD_YYYY.json.gz|
|Personas|https://files.tmdb.org/p/exports/person_ids_MM_DD_YYYY.json.gz|
|Colecciones|https://files.tmdb.org/p/exports/collection_ids_MM_DD_YYYY.json.gz|
|TV Networks|https://files.tmdb.org/p/exports/tv_network_ids_MM_DD_YYYY.json.gz|
|Keywords|https://files.tmdb.org/p/exports/keyword_ids_MM_DD_YYYY.json.gz|
|Compañías Productoras|https://files.tmdb.org/p/exports/production_company_ids_MM_DD_YYYY.json.gz|
