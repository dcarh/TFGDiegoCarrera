# Regiones

## ¿Cómo funciona el soporte de regiones en TMDB?

Hay dos aspectos de las regiones en TMDB que deben explicarse. El primero es el nuevo parámetro de región.

El parámetro de región actuará como un filtro para buscar y mostrar información de fechas de lanzamiento coincidentes. Se espera que este parámetro sea un código ISO 3166-1 (https://en.wikipedia.org/wiki/ISO_3166-2).

Por ejemplo, si estás buscando la película "Whiplash" y quieres mostrar la fecha de lanzamiento en Alemania (para acompañar la traducción alemana), puedes realizar una consulta de la siguiente manera:

    Ejemplo de solicitud en alemán

    curl --request GET \
        --url 'https://api.themoviedb.org/3/search/movie?query=Whiplash&language=de-DE&region=DE' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'

En este caso, la región simplemente actúa como un filtro de presentación. En caso de que no tengamos una fecha de lanzamiento registrada para el país que estás buscando, simplemente volvemos al lanzamiento principal como siempre. Esto es lo mismo que no especificar el parámetro de región.

Donde esto puede ser sorprendente es con el filtro with_release_type que puede funcionar junto con la región. Digamos que estás buscando películas que estén en los cines en Alemania esta semana. Es fácil, ahora podemos construir esta consulta:

    Ejemplo de solicitud teatral en alemán

    curl --request GET \
        --url 'https://api.themoviedb.org/3/discover/movie?language=de-DE&region=DE&release_date.gte=2016-11-16&release_date.lte=2016-12-02&with_release_type=2|3' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'

Por supuesto, puedes especificar cualquier tipo de lanzamiento como se encuentra en nuestra documentación (https://developer.themoviedb.org/reference/movie-release-dates). Si no especificas with_release_type mientras usas el parámetro de región en discover, la región simplemente actúa como un filtro que busca películas que cumplan con tus criterios de filtro y tengan, como mínimo, una fecha de lanzamiento coincidente para el país especificado.

Tipos de Lanzamiento:

|Tipo|Lanzamiento|
|-|-|
|1|Premiere|
|2|Teatral (limitado) (Theatrical)|
|3|Teatral (Theatrical)|
|4|Digital|
|5|Físico|
|6|TV|
