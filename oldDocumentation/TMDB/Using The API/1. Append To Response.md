# Append To Response

append_to_response es una forma fácil y eficiente de añadir solicitudes adicionales a cualquier espacio de nombres de nivel superior. Los métodos de detalles de películas, programas de televisión, temporadas de televisión, episodios de televisión y personas admiten un parámetro de consulta llamado append_to_response. Esto hace posible realizar sub-solicitudes dentro del mismo espacio de nombres en una sola solicitud HTTP. Cada solicitud se agregará a la respuesta como un nuevo objeto JSON.

Aquí tienes un ejemplo rápido. Supongamos que deseas obtener los detalles de una película y los videos para esa película. Normalmente pensarías que tendrías que realizar dos solicitudes:

    https://api.themoviedb.org/3/movie/157336?api_key=API_KEY
    https://api.themoviedb.org/3/movie/157336/videos?api_key=API_KEY

Pero con append_to_response, puedes realizar una sola solicitud:

    https://api.themoviedb.org/3/movie/157336?api_key=API_KEY&append_to_response=videos

Incluso más potente, puedes realizar múltiples solicitudes, simplemente separa los valores por comas:

    https://api.themoviedb.org/3/movie/157336?api_key=API_KEY&append_to_response=videos,images


📘 Nota

    Cada método seguirá respondiendo a los parámetros de consulta admitidos por cada solicitud individual. Esto es especialmente relevante para las imágenes, ya que tu parámetro de idioma filtrará las imágenes. Aquí es donde el parámetro include_image_language puede ser útil, como se describe en la página de idioma de imágenes.
