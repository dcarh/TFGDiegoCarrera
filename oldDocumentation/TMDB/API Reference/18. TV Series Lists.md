Obtener una lista de programas de televisión que se están emitiendo hoy.

    curl --request GET
        --url 'https://api.themoviedb.org/3/discover/tv?language=en-US&page=1&sort_by=popularity.desc&timezone=America%2FNew_York&include_null_first_air_dates=false'

## Se Emite En Los Próximos 7 Días (On The Air)

GET https://api.themoviedb.org/3/tv/on_the_air

Obtén una lista de series que se emiten en los próximos 7 días.

Llamada de descubrimiento equivalente:

    curl --request GET \
        --url 'https://api.themoviedb.org/3/discover/tv?include_adult=false&language=en-US&page=1&sort_by=popularity.desc&air_date.lte={max_date}&air_date.gte={min_date}' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'

#### PARÁMETROS DE CONSULTA

- language (string)
- page (int32)
- timezone (string). Código de zona horaria de IANA.

#### RESPUESTA

    Código de estado: 200

## Mejor Valoradas (Top Rated)

GET https://api.themoviedb.org/3/tv/top_rated

Obtén una lista de series de TV ordenadas por puntuación media.

Llamada de descubrimiento equivalente:

    curl --request GET \
        --url 'https://api.themoviedb.org/3/discover/tv?include_adult=false&language=en-US&page=1&sort_by=vote_average.desc&vote_count.gte=200' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'

#### PARÁMETROS DE CONSULTA

- language (string)
- page (int32)
- timezone (string). Código de zona horaria de IANA.

#### RESPUESTA

    Código de estado: 200
