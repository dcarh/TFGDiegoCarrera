# Solicitudes

- La mayoría de las solicitudes a la API utilizarán el método POST.

- La URL base es: https://api.igdb.com/v4

- Defines qué endpoint deseas consultar al agregar /{nombre del endpoint} a la URL base, por ejemplo: https://api.igdb.com/v4/games

- Incluye tu ID de cliente y el token de acceso en el ENCABEZADO de tu solicitud para que tus encabezados se vean de la siguiente manera.

    - Ten cuidado con las mayúsculas. "Bearer" debe codificarse directamente delante de tu access_token.


    Client-ID: ID de Cliente
    Authorization: Bearer access_token

Utilizas el BODY de tu solicitud para especificar los campos que deseas recuperar, así como cualquier otro filtro, orden, etc.

#### Ejemplo:

Si tu ID de cliente es "abcdefg12345" y tu access_token es "access12345token", una solicitud simple para obtener información sobre 10 juegos sería:


    POST: https://api.igdb.com/v4/games
    Client-ID: abcdefg12345
    Authorization: Bearer access12345token
    Body: "fields *;"

Nota: Si intentas realizar estas solicitudes a través del navegador, te encontrarás con errores de CORS, ya que la API no permite solicitudes directas desde navegadores. Puedes obtener más información sobre CORS y cómo solucionar este problema en la sección de Proxy de CORS.
