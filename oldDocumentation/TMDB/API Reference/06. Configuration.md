# Configuración

## Detalles

GET https://api.themoviedb.org/3/configuration

Consulta los detalles de configuración de la API.

Los datos devueltos aquí en el endpoint de configuración están diseñados para proporcionar parte de la información necesaria que necesitarás al integrar nuestra API.

Por ejemplo, puedes obtener una lista de tamaños de imagen válidos y las direcciones de imagen válidas.

#### POSIBLES RESPUESTAS

    Código de estado: 200

## Países

GET https://api.themoviedb.org/3/configuration/countries

Obtén la lista de países (ISO 3166-1) que usa TMDB.

#### PARÁMETROS DE CONSULTA

- language (string). Por ejemplo, en-US.

## Traducciones Primarias

GET https://api.themoviedb.org/3/configuration/primary_translations

Obtén una lista de las traducciones oficialmente soportadas por TMDB.

Aunque técnicamente es posible agregar una traducción en cualquiera de los idiomas [https://developer.themoviedb.org/reference/configuration-languages] que hemos agregado a TMDB (no restringimos el contenido), los que se enumeran en este método son los que también admitimos para la localización del sitio web, lo que significa que son traducciones "primarias".

Todos estos están especificados como etiquetas IETF [https://en.wikipedia.org/wiki/IETF_language_tag] para identificar los idiomas que usamos en TMDB. Hay una excepción que son los idiomas de las imágenes [https://developer.themoviedb.org/docs/image-languages]. Actualmente, solo están designados por una etiqueta ISO-639-1. Esto es una mejora planificada para el futuro.

Siempre estamos abiertos a agregar más si crees que se debería agregar uno nuevo. Puedes preguntar acerca de agregar una nueva traducción primaria publicando en los foros [https://www.themoviedb.org/talk/category/5047954b760ee3369b000001].

Otra cosa que mencionar, estas son las traducciones que se asignan a nuestro proyecto de traducción del sitio web. Puedes ver y contribuir a ese proyecto aquí [https://app.localeapp.com/projects/8267].

#### POSIBLES RESPUESTAS

    Código de estado: 200
