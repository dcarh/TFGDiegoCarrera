# Temporadas de TV

## Detalles

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}

Consulta los detalles de una temporada de una serie de televisión.

Este método admite el uso de append_to_response. Lee más sobre esto aquí.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetro obligatorio.

- season_number (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- append_to_response (string). Lista separada por comas de puntos finales dentro de este espacio de nombres, máximo 20 elementos.

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Créditos Agregados

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}/aggregate_credits

Obtener los créditos agregados (elenco y equipo) que se han agregado a una temporada de una serie de televisión.

    📘 Nota

    Esta llamada difiere de la llamada principal de créditos en que no devuelve la temporada más nueva. En cambio, es una vista de todo el elenco y equipo para todos los episodios que pertenecen a una serie de televisión.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetro obligatorio.

- season_number (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Cambios

GET https://api.themoviedb.org/3/tv/season/{season_id}/changes

Obtener los cambios recientes para una temporada de una serie de televisión.

Obtén los cambios para una temporada de una serie de televisión. Por defecto, solo se devuelven las últimas 24 horas.

Puedes consultar hasta 14 días en una sola consulta utilizando los parámetros de consulta start_date y end_date.

    📘 Nota

    Los cambios en las temporadas de las series de televisión son un poco diferentes que los cambios en las películas en el sentido de que hay algunas ediciones en episodios que crearán una entrada de cambio de nivel superior en el nivel de la temporada. Estos se pueden encontrar bajo las claves de episodio. Estas claves contendrán un episode_id. Puedes usar los métodos de cambios de episodio para buscarlos individualmente.

#### PARÁMETROS DE RUTA

- season_id (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- end_date (string)

- page (int32)

- start_date (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Imágenes

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}/images

Obtener las imágenes que pertenecen a una temporada de una serie de televisión.

Este método devolverá los pósters que se han agregado a una temporada de una serie de televisión.

    📘 Nota

    Si tienes un idioma especificado, actuará como un filtro en los elementos devueltos. Puedes usar el parámetro include_image_language para consultar idiomas adicionales.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetro obligatorio.

- season_number (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- include_image_language (string). Especifica una lista separada por comas de valores ISO-639-1 para consultar, por ejemplo: en,null.

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

## Proveedores de Transmisión

GET https://api.themoviedb.org/3/tv/{series_id}/season/{season_number}/watch/providers

Obtener la lista de proveedores de transmisión que tenemos para una temporada de una serie de televisión.

Impulsado por nuestra asociación con JustWatch, puedes consultar este método para obtener una lista de disponibilidad de transmisión/alquiler/compra por país y proveedor.

Esto no devolverá enlaces profundos completos, sino que es información suficiente para mostrar lo que está disponible y dónde.

Puedes vincular a la URL proporcionada por TMDB para ayudar a apoyar a TMDB y proporcionar los enlaces profundos reales al contenido.

    📘 Atribución de JustWatch Requerida

    Para usar estos datos, debes atribuir la fuente de los datos como JustWatch. Si encontramos algún uso que no cumpla con estos términos, revocaremos el acceso a la API.

#### PARÁMETROS DE RUTA

- series_id (int32). Parámetro obligatorio.

- season_number (int32). Parámetro obligatorio.

#### PARÁMETROS DE CONSULTA

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200
