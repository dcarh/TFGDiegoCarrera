# Colecciones

## Detalles

GET https://api.themoviedb.org/3/collection/{collection_id}

Obtén detalles de una colección según su ID

#### PARÁMETROS DE RUTA

- collection_id (int32). Parámetro obligatorio

#### PARÁMETROS DE CONSULTA

language (string)

#### POSIBLES RESPUESTAS

    Código de estado: 200

## Imágenes

GET https://api.themoviedb.org/3/collection/{collection_id}/images

Obtener las imágenes que pertenecen a una colección.

Este método devolverá los fondos y carteles que pertenecen a una colección.

    📘 Nota

    Si tienes un idioma especificado, actuará como un filtro en los elementos devueltos. Puedes utilizar el parámetro include_image_language para consultar idiomas adicionales.

#### PARÁMETROS DE RUTA

collection_id (int32). Parámetro obligatorio

#### PARÁMETROS DE CONSULTA

- include_image_language (string). Especifica una lista separada por comas de valores ISO-639-1 para consultar, por ejemplo: en,null

- language (string)

#### POSIBLES RESPUESTAS

    Código de estado: 200
