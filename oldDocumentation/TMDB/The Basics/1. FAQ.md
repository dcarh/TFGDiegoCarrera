# Preguntas Frecuentes

## ¿Qué es la API de TMDB?
El servicio de API está destinado a aquellos interesados en utilizar nuestras imágenes y/o datos de películas, programas de televisión o actores en sus aplicaciones. Nuestra API es un sistema que proporcionamos para que usted y su equipo obtengan y utilicen nuestros datos y/o imágenes de manera programática.

## ¿Cómo solicito una clave de API?
Puede solicitar una clave de API haciendo clic en el enlace "API" en la barra lateral izquierda dentro de la página de configuración de su cuenta.

## ¿Hay un SLA (Acuerdo de nivel de servicio)?
Actualmente no proporcionamos un SLA. Sin embargo, hacemos todo lo posible por mantener nuestro servicio en línea y accesible. Puede ver nuestra página de estado aquí [https://status.themoviedb.org].

## ¿Hay envoltorios o bibliotecas de API que pueda usar?
¡Claro que sí! Encuéntralos aquí.

## ¿Y sobre SSL?
Actualmente está disponible en toda la API. Esto incluye tanto los puntos finales de la API como los activos servidos a través de nuestra CDN. Recomendamos encarecidamente que utilice SSL [https://developer.themoviedb.org/docs/wrappers-and-libraries].

## ¿Hay un servicio comercial?
Sí. Puede ponerse en contacto con nuestro equipo de ventas enviando un correo electrónico a info@themoviedb.org.

## ¿Cuál es la diferencia entre una API comercial y una API para desarrolladores?
Una API comercial es para proyectos comerciales y una API para desarrolladores es para desarrolladores. Su proyecto se considera comercial si el propósito principal es generar ingresos en beneficio del propietario.

## ¿La clave de API tiene algún costo?
Nuestra API es gratuita para su uso con fines no comerciales, siempre y cuando atribuya a TMDB como la fuente de los datos y/o imágenes. Si está interesado en obtener una licencia para usar nuestra API y/o nuestros datos/imágenes con fines comerciales, póngase en contacto con info@themoviedb.org.

## ¿La API cambia alguna vez? ¿Cómo puedo enterarme de las nuevas funciones?
Sí, puede cambiar de vez en cuando. Intentamos publicar estas actualizaciones relevantes en la documentación oficial. También puede mantenerse informado consultando nuestro registro de cambios [https://developer.themoviedb.org/changelog].

## ¿Cuáles son los requisitos de atribución?
Debe usar el logotipo de TMDB para identificar el uso de las API de TMDB. Debe colocar el siguiente aviso de manera destacada en su aplicación: "Este producto utiliza la API de TMDB, pero no está respaldado ni certificado por TMDB".

Cualquier uso del logotipo de TMDB en su aplicación debe ser menos prominente que el logotipo o marca que describa principalmente la aplicación, y su uso del logotipo de TMDB no debe implicar ningún respaldo por parte de TMDB. Cuando se atribuye a TMDB, la atribución debe estar dentro de la sección "Acerca de" o "Créditos" de su aplicación.

Al usar un logotipo de TMDB, le exigimos que utilice uno de nuestros logotipos aprobados [https://www.themoviedb.org/about/logos-attribution].

## ¿Puedo realizar cambios en la API?
No, no puede. Nuestra API es de código cerrado.

## ¿Existen requisitos de marca?
Nuestro logotipo no debe modificarse en cuanto a color, relación de aspecto, volteado o rotado, excepto donde se indique lo contrario.

Nuestro logotipo puede ser blanco, negro o alguno de los colores aprobados utilizados en nuestra marca. Para obtener una lista de logotipos oficiales, consulte nuestra página de logotipos y atribuciones [https://www.themoviedb.org/about/logos-attribution].

Al referirse a TMDB, debe usar el acrónimo "TMDB" o el nombre completo "The Movie Database". Cualquier otro nombre no es aceptable. Al enlazar de vuelta a nuestro sitio web, apunte su enlace a:

https://www.themoviedb.org

Si va a colocar nuestro nombre de empresa o logotipo en cualquier mercancía o embalaje de productos, consulte con nosotros antes para obtener aprobación.

## Aviso legal de la API
No reclamamos la propiedad de ninguna de las imágenes o datos en la API. Cumplimos con la Ley de Derechos de Autor del Milenio Digital (DMCA) y retiramos de manera expedita el contenido infractor cuando se nos notifica adecuadamente. Cualquier dato y/o imágenes que cargue nos concede expresamente una licencia para usarlos. Se prohíbe el uso de las imágenes y/o datos en conexión con contenido difamatorio, obsceno, pornográfico, abusivo u ofensivo de cualquier otra manera.
