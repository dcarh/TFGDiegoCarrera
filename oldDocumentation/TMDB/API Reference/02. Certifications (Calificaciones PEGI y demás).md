# Certificaciones De Películas y Series de TV

Obtener una lista actualizada de las certificaciones de películas oficialmente admitidas en TMDB:

    GET https://api.themoviedb.org/3/certification/movie/list

Lo mismo pero para series de TV: 

    GET https://api.themoviedb.org/3/certification/tv/list

#### Posibles respuestas

    200
