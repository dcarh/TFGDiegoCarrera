# Ejemplos

Se recomienda probar tus consultas en un visor de API como Postman o Insomnia antes de utilizar código. Esto te ayuda a encontrar problemas mucho antes.


#### Un ejemplo muy básico para recuperar el nombre de 10 juegos:

https://api.igdb.com/v4/games/

    fields name; limit 10;

------

#### Obtener toda la información de un juego específico (1942 es el ID de un juego):

https://api.igdb.com/v4/games/

    fields *; where id = 1942;

------

#### Excluir datos irrelevantes de tu consulta (eliminar alternative_name de los resultados):

https://api.igdb.com/v4/platforms/

    fields *;
    exclude alternative_name;

------

#### Obtener todos los juegos de géneros específicos (puedes separar múltiples IDs con comas y deben estar rodeados por paréntesis):

https://api.igdb.com/v4/genres/

    fields *; where id = (8,9,11);

------

#### Contar el total de juegos con una calificación superior a 75:

https://api.igdb.com/v4/games/count

    where rating > 75;

------

#### Ordenar por calificación:

https://api.igdb.com/v4/games/

    fields name,rating; sort rating desc;

------

#### Juegos próximos para PlayStation 4:

https://api.igdb.com/v4/release_dates/

    fields *; where game.platforms = 48 & date > 1538129354; sort date asc;

------

#### Juegos recientemente lanzados para PlayStation 4:

    fields *; where game.platforms = 48 & date < 1538129354; sort date desc;

------

#### Buscar y devolver campos específicos:

https://api.igdb.com/v4/games/

    search "Halo"; fields name,release_date.human;

------

#### Buscar juegos pero excluir versiones (ediciones):

https://api.igdb.com/v4/games/

    fields name, involved_companies; search "Assassins Creed"; where version_parent = null;

------

#### Buscar en todos los puntos finales:

https://api.igdb.com/v4/search

    fields *; search "sonic the hedgehog"; limit 50;

------

#### Obtener versiones (ediciones) de un juego:

https://api.igdb.com/v4/game_versions/

    fields game.name,games.name; where game = 28540;

------

#### Obtener el juego principal para una versión:

https://api.igdb.com/v4/games/

    fields version_parent.*; where id = 39047;

El objeto resultante contendrá todos los juegos principales

------

#### Obtener todos los juegos que son exclusivos de PlayStation 4:

    fields name,category,platforms;
    where category = 0 & platforms = 48;

------

#### Obtener todos los juegos que se lanzaron solo en PlayStation 4 Y PC:

    fields name,category,platforms;
    where category = 0 & platforms = {48,6};
