# Proveedores

# Regiones Disponibles

GET https://api.themoviedb.org/3/watch/providers/regions

Obtener la lista de los países para los cuales tenemos datos de proveedores de transmisión (OTT/streaming).

#### PARÁMETROS DE CONSULTA

- language (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200

# Proveedores de Películas

GET https://api.themoviedb.org/3/watch/providers/movie

Obtener la lista de proveedores de transmisión que tenemos para películas.

Devuelve una lista de datos de proveedores de transmisión (OTT/streaming) que tenemos disponibles para películas. Puedes especificar un parámetro watch_region si deseas filtrar aún más la lista por país.

#### PARÁMETROS DE CONSULTA

- language (string)
- watch_region (string)

#### POSIBLES RESPUESTAS

    Código de estatus: 200
