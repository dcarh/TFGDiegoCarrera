# Compañías

## Detalles

GET https://api.themoviedb.org/3/company/{company_id}

Obtén detalles de una compañía según su ID

#### PARÁMETROS DE RUTA

- company_id (int32). Parámetro obligatorio

#### POSIBLES RESPUESTAS

    Código de estado: 200

## Nombres Alternativos

GET https://api.themoviedb.org/3/company/{company_id}/alternative_names

Obtén nombres de una compañía según su ID

#### PARÁMETROS DE RUTA

- company_id (int32). Parámetro obligatorio

#### POSIBLES RESPUESTAS

    Código de estado: 200

## Imágenes

GET https://api.themoviedb.org/3/company/{company_id}/images

Obtén logos de una compañía según su ID


    📘 Nota

    Hay dos formatos de imagen compatibles para empresas: PNG y SVG. Puedes ver qué tipo es el archivo original mirando el campo file_type. Preferimos SVG, ya que son independientes de la resolución y, como tal, el ancho y alto solo están ahí para reflejar el activo original que se cargó. Un SVG puede escalarse correctamente más allá de esas dimensiones si se llama como un PNG.

Para obtener más información sobre cómo se pueden utilizar SVG y PNG, lee este documento [https://developer.themoviedb.org/docs/image-basics].

#### PARÁMETROS DE RUTA

- company_id (int32). Parámetro obligatorio

#### POSIBLES RESPUESTAS

    Código de estado: 200
