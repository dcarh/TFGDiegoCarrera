# Seguimiento de Cambios

Si estás interesado en realizar un seguimiento de los cambios mientras ocurren en TMDB, hemos diseñado el sistema de "cambios" para ayudarte con esto. Hay dos aspectos en esto: primero, realizar un seguimiento de qué IDs han cambiado y luego, segundo, llamar a esos cambios individuales.

## Por Tipo de Medio
Hay tres endpoints principales que puedes llamar para obtener una lista de IDs cambiados. Las listas de cambios de películas [https://developer.themoviedb.org/reference/changes-movie-list], personas [https://developer.themoviedb.org/reference/changes-people-list] y programas de televisión [https://developer.themoviedb.org/reference/changes-tv-list]. Estos endpoints devolverán una lista de elementos que han cambiado en las últimas 24 horas (por defecto, pero se puede extender a 14 días). Con un ID en mano, puedes luego llamar al historial de cambios individual del elemento.

## Por ID de Medio
Si tienes un ID en mano, puedes llamar a cualquiera de los endpoints de cambio de ID de medio (aquí tienes un ejemplo de películas [https://developer.themoviedb.org/reference/movie-changes]). Esta llamada devolverá los datos reales a nivel de campo que se cambiaron, al igual que nuestros registros de cambios públicos que puedes encontrar en el sitio web. Puedes consumir estos cambios en su totalidad o tomar selectivamente los datos que son importantes para ti.

En general, es una buena idea mantenerse sincronizado con nuestros cambios para que puedas mostrar la información más actualizada y precisa.
