# Tendencias

## All

GET https://api.themoviedb.org/3/trending/all/{time_window}

Obtener las películas, programas de televisión y personas más populares.

Esta llamada es similar a cómo funciona la búsqueda múltiple en el sentido de que devolvemos varios tipos de medios (películas, programas de televisión y personas) en una sola llamada para obtener los datos más populares en todo TMDB.

Si desea obtener solo los datos populares de un tipo de medio específico, utilice uno de los métodos específicos:

1. Películas populares [https://developer.themoviedb.org/reference/trending-movies]
2. Programas de televisión populares [https://developer.themoviedb.org/reference/trending-tv]
3. Personas populares [https://developer.themoviedb.org/reference/trending-people]

#### PARÁMETROS DE RUTA

- time_window (string). Parámetro obligatorio. Predeterminado: day.

#### PARÁMETROS DE CONSULTA

- language (string). Código ISO-639-1-ISO-3166-1

#### POSIBLES RESPUESTAS

    Código de estatus: 200
