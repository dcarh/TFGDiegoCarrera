# Basics
Cómo construir una URL de imagen

Notarás que los objetos de películas, programas de televisión y personas contienen referencias a diferentes rutas de archivos. Para generar una URL de imagen completamente funcional, necesitarás 3 piezas de datos. Estas piezas son una **base_url**, un **file_size** y un **file_path**.

Las dos primeras piezas se pueden obtener llamando a la API /configuration [https://developer.themoviedb.org/reference/configuration-details] y la tercera es la ruta de archivo que deseas obtener en un objeto de medios específico. Aquí tienes cómo se ve una URL completa de imagen si el poster_path es /1E5baAaEse26fej7uHcjOgEE2t2.jpg para una película, y estás buscando el tamaño w500:

    Ejemplo

    https://image.tmdb.org/t/p/w500/1E5baAaEse26fej7uHcjOgEE2t2.jpg

Los logotipos de empresas y redes están disponibles en dos formatos, SVG y PNG. Todos los campos **logo_path** devolverán un .png. Esto se hace para mantener la compatibilidad hacia atrás, ya que el soporte para SVG se agregó después del hecho.

Cuando examines los métodos de imagen, hay un nuevo campo llamado **file_type** que te mostrará la versión original del recurso que se cargó. Para los archivos SVG, debes llamar al tamaño original de la imagen, ya que no los redimensionamos. Si prefieres obtener archivos PNG, puedes llamar a cualquier tamaño que desees, al igual que normalmente.

Tomemos, por ejemplo, el logotipo de Netflix (**wwemzKWzjKYJFfCeiB57q3r4Bcm.svg**), puedes llamar a cualquiera de los siguientes:

    Ejemplo

    https://image.tmdb.org/t/p/original/wwemzKWzjKYJFfCeiB57q3r4Bcm.svg
    https://image.tmdb.org/t/p/original/wwemzKWzjKYJFfCeiB57q3r4Bcm.png
    https://image.tmdb.org/t/p/w500/wwemzKWzjKYJFfCeiB57q3r4Bcm.png
