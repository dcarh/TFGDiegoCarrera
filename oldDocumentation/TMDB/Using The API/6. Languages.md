# Idiomas

Aprende acerca de los idiomas en TMDB.

TMDB se esfuerza por estar localizado siempre que sea posible. Aunque la mayoría de nuestros endpoints de metadatos admiten datos traducidos, aún existen algunas brechas que no lo hacen. Las dos áreas principales que no están traducidas son los nombres de personas y los personajes. Estamos trabajando para admitir esto.

## ISO 639-1 (https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes)
El sistema de códigos de idioma que utilizamos es ISO 639-1. Desafortunadamente, hay varios idiomas que no tienen una representación ISO-639-1. Podríamos decidir actualizar a ISO-639-3 en el futuro, pero actualmente no tenemos planes inmediatos para hacerlo.

## ISO 3166-1 (https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2).
Por lo general, encontrarás nuestros códigos de idioma unidos a un código de país en el formato de en-US. Los códigos de país utilizados aquí son ISO 3166-1.

    📘 Nota

    Las imágenes aún no admiten la notación idioma-PAÍS. Esto se mejorará en el futuro. Lee la documentación de idioma de imágenes para aprender cómo sortear parcialmente esta limitación.

Ahora que sabes cómo funcionan los idiomas, veamos algunas solicitudes de ejemplo.

Ejemplo en inglés

    curl --request GET \
        --url 'https://api.themoviedb.org/3/tv/1399?language=en-US' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'

Ejemplo en portugués

    curl --request GET \
        --url 'https://api.themoviedb.org/3/movie/popular?language=pt-BR' \
        --header 'Authorization: Bearer ACCESS_TOKEN' \
        --header 'accept: application/json'
