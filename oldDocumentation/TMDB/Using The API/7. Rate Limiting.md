📘 Límites de Tarifas Antiguos

    A partir del 16 de diciembre de 2019, hemos desactivado los límites de tarifas originales de la API (40 solicitudes cada 10 segundos). Si tienes alguna pregunta al respecto, dirígete a nuestro foro de soporte de API (https://www.themoviedb.org/talk/category/5047958519c29526b50017d6).

Aunque nuestros límites de tarifas antiguos se han desactivado durante algún tiempo, todavía tenemos algunos límites superiores para ayudar a mitigar el scraping masivo innecesariamente alto. Estos límites se sitúan en algún lugar alrededor de las 50 solicitudes por segundo. Este límite podría cambiar en cualquier momento, así que sé respetuoso con el servicio que hemos construido y respeta el código de estado 429 si lo recibes.
