# Géneros

## Lista de Películas

GET https://api.themoviedb.org/3/genre/movie/list

Obtén la lista de géneros oficiales para películas.

#### PARÁMETROS DE CONSULTA

- language (string). Por ejemplo: en.

#### POSIBLES RESPUESTAS

    Código de estado: 200
